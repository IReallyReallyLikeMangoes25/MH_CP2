## Simple Grade Book Project
This program allows a user to manage students using a gradebook.

## How To Use
Open main.py and run the code!

## Project Features
 - Track student grades, average grade, and letter grade
 - View class average
 - Add new students
 - View all students
 - Keep track of what grade a student is in

## Planned Features
 - Visualisation of grade history
 - Class specific letter grades
 - Grade Point Average calculator
